Lesson 04 · Sensitivity Analysis for Causal Inference

The Robustness Value & Reading a Contour Plot

Mission tie-in: this is the skill the mission singles out — reading an OVB contour plot and a robustness value from sensemakr / dml.sensemakr output and saying what it implies. The same reading transfers from linear regression to causal ML.

1Two numbers describe any confounder

The E-value works on the risk-ratio scale. Cinelli & Hazlett re-cast the same idea in regression terms, which is what most causal-ML output speaks.[1] Any unobserved confounder U is summarised by two partial R² values:

R²D~U = share of leftover variation in treatment that U explains
R²Y~U = share of leftover variation in outcome that U explains

Given those two, the worst-case bias on the estimate is pinned down. That is the same two-leg logic as the E-value (treatment leg × outcome leg) — now scale-free and directly comparable to the covariates you already fitted.[1]

2The robustness value collapses it to one number

For a quick headline, assume the confounder is equally strong on both legs and ask: how large must that shared partial R² be to drag the estimate to the null? That single number is the robustness value.[1]

Read RV like this. RV = 0.15 means a confounder explaining 15% of the residual variation in both treatment and outcome would erase the result. Near 0 = fragile; near 1 = only an all-explaining confounder could do it. There is also an RV for the significance boundary (the analogue of L01's CI-limit E-value) — always read both.

3The contour plot — the skill that pays the rent

The contour plot is the two-number picture. Treatment-leg strength on the x-axis, outcome-leg strength on the y-axis; the curves show what the estimate becomes for each combination. The bold curve is where the estimate hits the null. Your measured covariates are plotted as reference dots — so you read robustness by comparison, not in the abstract.[1]

4Why this is the causal-ML bridge

The decisive point for the mission: this machinery is no longer tied to linear regression. Chernozhukov, Cinelli and colleagues extended omitted-variable-bias sensitivity to double/debiased machine learning, so an ATE estimated with flexible ML still gets a robustness value and a contour plot.[2] The package dml.sensemakr produces output you read exactly as above.[3]

Transfer. When a causal-ML paper shows an "Austen plot" or a robustness value for its DML estimate, it is the same two-leg, benchmark-against-covariates reading you just practised — not a new skill to learn.
